# Requirements: IEI SIES GST (ECS)

**Defined:** 2026-09-20
**Core Value:** Deliver a world-class institutional digital presence that elevates the ECS student chapter through precision engineering aesthetics, strict typography, seamless dual-theming, and verifiable digital membership.

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Visual Foundation & Theming

- [ ] **VIS-01**: User can switch between Theme A (Default: white / black / blue / orange) and Theme B (Alternative: black / white / #664EEA) with persistent preference.
- [ ] **VIS-02**: Interface renders with locked Helvetica typography across all viewport sizes with strict editorial hierarchy.
- [ ] **VIS-03**: All pages and interactive elements maintain smooth kinetic scrolling and fluid animations with reduced-motion support.

### Signature Experiences

- [ ] **SIGN-01**: User experiences cinematic IEI identity intro animation upon landing.
- [ ] **SIGN-02**: User sees the Default theme blueprint → structure → reality visual transformation.
- [ ] **SIGN-03**: User experiences the Alternative theme dot → wireframe → 3D → material visual transformation.
- [ ] **SIGN-04**: User navigates through LinusBio-inspired sequential storytelling scrollytelling stages.
- [ ] **SIGN-05**: User views M3-inspired editorial visual compositions throughout institutional sections.

### Team & Leadership

- [ ] **TEAM-01**: User interacts with the team group photograph with interactive member highlight hotspots.
- [ ] **TEAM-02**: User can view official Faculty Leadership profiles (Dr. Shubhangi Kharache — HOD, Prof. Jasmin Hirani — Student Branch Coordinator).
- [ ] **TEAM-03**: User can explore the 7 official domain teams (Technical, Industry Outreach & Admin, Publicity, Creative, Design, Media, Editorial).
- [ ] **TEAM-04**: Domain teams display 4-tier hierarchy (Mentor, Head, Coordinator, Volunteer).
- [ ] **TEAM-05**: Core Council section displays transparent pending induction status while awaiting formal faculty ratification without fabricated names.

### Member Verification & Credentials

- [ ] **VERIF-01**: User can search and verify active membership credentials by Member ID.
- [ ] **VERIF-02**: User can view individual member profile pages with verified credentials, domain, and role.
- [ ] **VERIF-03**: User scanning member QR codes is routed directly to the verified mobile profile (`/m/[memberId]`).

### Institutional Content & Catalogs

- [ ] **CONT-01**: User can browse the About section detailing the ECS department, mission, and engineering principles.
- [ ] **CONT-02**: User can browse the Activities catalog with past and upcoming chapter initiatives.
- [ ] **CONT-03**: User can view Events with dynamic detail pages (`/events/[slug]`).
- [ ] **CONT-04**: User can browse curated Resources and Visual Gallery.
- [ ] **CONT-05**: User can access official Contact details and institutional channels.
- [ ] **CONT-06**: Any attempt to navigate to `/join` or join forms permanently redirects to `/` with no join buttons displayed.

## v2 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Community & Expansion

- **COMM-01**: Digital member certificate PDF export and wallet pass.
- **COMM-02**: Interactive event calendar ICS feed export.
- **COMM-03**: Student project showcase directory linked to technical domain.

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| "Join IEI" / "Join Chapter" forms | Chapter membership and inductions are managed strictly through institutional academic protocols |
| Fabricated member / event data | Official data will be supplied directly by the faculty board; no unofficial information will be invented |
| Non-Helvetica typography | Helvetica is locked globally across all views as required by design specification |
| Self-serve member registration portal | Members are officially inducted and credentialed by the chapter council |
